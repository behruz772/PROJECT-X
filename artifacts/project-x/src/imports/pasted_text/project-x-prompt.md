PROJECT X — MASTER PRODUCT PROTOTYPE PROMPT
VERSION 0.1

ROLE

Act as a world-class product designer, UX/UI designer, startup product strategist, social-network architect and AI product designer.

You are designing a completely new global social ecosystem called PROJECT X.

Do NOT simply clone Instagram, TikTok, Discord, LinkedIn, Facebook or any other existing platform.

You may learn from successful interaction patterns, but PROJECT X must have its own identity, information architecture and user experience.

The goal is to create a clickable, realistic, premium product prototype that feels like a serious global technology company could have built it.

==================================================
1. PRODUCT VISION
==================================================

PROJECT X is a global digital ecosystem where people:

CREATE
CONNECT
COLLABORATE
GROW

The platform combines:

- Social media
- Creator platform
- Communities
- Messaging
- AI companion
- AI creation tools
- Professional identity
- Talent discovery
- Global communication
- Events

The central philosophy is:

"Your value is more than your follower count."

PROJECT X should make users feel that they are not merely consumers of content.

They are creators, collaborators, learners, builders and members of communities.

The platform should feel like:

"My digital world."

3. DESIGN PHILOSOPHY
==================================================

The design must be:

- Premium
- Modern
- Minimal
- Fast-looking
- Intelligent
- Friendly
- Futuristic
- Professional
- Human

Avoid excessive gradients, excessive glassmorphism, excessive neon and unnecessary visual effects.

Do NOT make it look like a gaming dashboard.

Do NOT make every component look futuristic.

Use futuristic elements only where they improve the experience.

The design should feel like a combination of:

premium consumer technology
+
creator platform
+

==================================================
37. PRODUCT QUALITY BAR
==================================================

Before considering the prototype complete, inspect every major flow.

Ask:

Can a first-time user understand the product?

Can a user create something?

Can a user discover another person?

Can a user find a collaborator?

Can a user understand Creator Level?

Can a user understand the AI Friend?

Can a user join a community?

Can two users communicate across languages?

Can a user understand what PROJECT X is?

If the answer is no, improve the design.
